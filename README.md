### 🏪 La Vest PDV

Complete **point-of-sale and management system** built with **Java 21 and Spring Boot**, running in production in a real clothing, footwear and perfume store. Registers the sale, updates inventory, manages store credit (crediário) and prints the receipt in a single action.

- Backend in **Java 21 + Spring Boot**, packaged with Maven
- **PostgreSQL** as the transactional database, running on Docker
- Sales, inventory and store credit (crediário) domain logic
- Automated tests (`./mvnw test`) and desktop installer for the store machine
- **Running in production in a real store**

**Tech:** `Java 21` `Spring Boot` `PostgreSQL` `Docker` `Maven`

### 🕵️ DeepFakes & AI Image Detector

AI-generated image **attribution** system: instead of only classifying real vs. fake, it identifies **which model** generated the image — **Google Gemini**, **DALL-E 3**, **Midjourney v6**, **Stable Diffusion**, **GANs** or **Human**.

- 96.65% accuracy
- Feature extraction with DenseNet121
- Inference with Multilayer Perceptron
- Balanced dataset with SMOTE
- Deployed on Hugging Face Spaces

**Tech:** `Python` `PyTorch` `TypeScript` `React` `FastAPI` `Docker` `Hugging Face Spaces`
