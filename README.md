## Projetos

### La Vest PDV

Sistema de ponto de venda e gestão para uma loja de roupas, calçados e perfumes. Roda em produção. Registra venda, atualiza estoque, controla crediário e imprime o recibo em uma única ação.

- Java 21 + Spring Boot, empacotado com Maven
- PostgreSQL rodando em Docker
- Regras de negócio para venda, estoque e crediário
- Testes automatizados (`./mvnw test`)
- Instalador desktop para a máquina da loja

`Java 21` `Spring Boot` `PostgreSQL` `Docker` `Maven`

[Repositório](https://github.com/kalil03/la-vest-pdv)

### DeepFakes & AI Image Detector

Sistema de atribuição de imagens geradas por IA: em vez de só classificar real ou fake, ele identifica qual modelo gerou a imagem (Gemini, DALL-E 3, Midjourney v6, Stable Diffusion, GANs ou humano).

- 96,65% de acurácia
- Extração de features com DenseNet121
- Classificação com MLP
- Dataset balanceado com SMOTE
- Deploy no Hugging Face Spaces

`Python` `PyTorch` `TypeScript` `React` `FastAPI` `Docker` `Hugging Face Spaces`

[Demo](https://huggingface.co/spaces/kalilzera/DeepFakes) · [Repositório](https://github.com/kalil03/DeepFakes)

### ReviewCheckIA

Análise de sentimento em português baseada em BERTimbau, treinado com mais de 187 mil avaliações reais do Mercado Livre. Classificação instantânea, sem depender de API externa.

- 95% de acurácia
- Fine-tuning do BERTimbau
- Pipeline de NLP para português
- Deploy no Hugging Face

`Python` `PyTorch` `FastAPI` `Hugging Face` `NLP` `Docker`

[Demo](https://huggingface.co/spaces/kalilzera/ReviewCheckIA) · [Repositório](https://github.com/kalil03/ReviewCheckIA)

### Bot WhatsApp

Bot em TypeScript com integração à API do Gemini, manipulação de mídia e downloaders de redes sociais. Construído sobre `whatsapp-web.js`.

- Codebase em TypeScript no Node.js
- Chat com IA (múltiplas personalidades) e transcrição de áudio
- Figurinhas, extração de áudio, efeitos e text-to-speech
- Download de vídeos do Instagram, TikTok, Facebook e X
- Processamento de mídia com FFmpeg

`TypeScript` `Node.js` `whatsapp-web.js` `Gemini API` `FFmpeg` `Docker`

[Repositório](https://github.com/kalil03/bot_whatsapp)
